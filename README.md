## 📁 Structure

```
30-days-30-website/

```

Each `dayN/` folder is a standalone project with its own setup instructions.

## 🛠️ Getting Started

Navigate into any day's folder and follow the README there:

```bash
cd day1
npm install
npm run dev
```
